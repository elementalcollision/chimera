## Why this is model nondeterminism, not platform

Three independent checks rule out v4.101/102/103 as the cause:

1. **`should_witness()` filters to chimera/+tests/ only.** Code at
   `chimera/core/act.py:1493` reads `write_targets` and returns
   only paths matching the foundational-code pattern. Mind/ writes
   never trigger the witness panel.

2. **Witness panel exception handler is fail-open.** Code at
   `act.py:1514-1517`:

   ```python
   except Exception:
       logger.exception("witness review crashed; treating as approved")
   ```

   Even if the panel were misconfigured and crashed, it would NOT
   block writes — it would log and let the completion proceed.

3. **v4.101 syntax_invalid only runs on `.py` files in `write_targets`.**
   No Python was written; no syntax check ran.

The agent's failure to call `code_exec` for the mind/ doc is a
model-side behavioral variation. v8 exhibited the same shape (hollow
doc with no content); v10 and v9 produced the doc correctly; v11
produced no doc at all. Across the 11-soak series, this task has
succeeded ~7 times and failed ~4 times — that's roughly the noise
floor for any single-shot model behavior.
