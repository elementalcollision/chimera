Citations & Notes

  1. LangGraph Store API — persistent cross-thread memory backed by Postgres/SQLite with optional vector search. LangGraph Persistence docs; AI Workshack.
  2. No built-in shared-filesystem KFM. Cross-agent state achievable via Store + filesystem, but not a first-class swarm-KFM primitive. LangGraph Platform.
  3. LangSmith captures per-node execution timelines, tool calls, and token usage as an implicit structured journal. LangSmith docs; AgentTrace (arXiv 2026).
  4. LangSmith observability + external attestation infrastructure needed. ERC-8004 Trust Oracle; x402 Attestations.
  5. No built-in proposer-quality scoring. Relies on LangSmith eval runners — not a real-time scoring primitive.
  6. interrupt() pauses execution at any node, awaiting external human approval — the canonical operator-gate. LangGraph HITL docs.
  7. LangSmith per-run token/cost tracking. Token budgets per graph via LangGraph Platform. Cycles budgets.
  8. No built-in provider tier escalation. Manual routing via custom model-selection nodes. LangChain model routing.
  9. Agent Server exposes MCP endpoint; langchain-mcp-adapters wraps MCP servers. MCP endpoint; adapters.
  10. No drift/anchor primitives. Drift Detection Patterns; Agent Drift (arXiv).
  11. Context overflow via summarisation; no density-scoring gate. Context overflow strategies.
  12. Peer discovery via LangGraph Platform deployments; no native decentralized discovery. LangGraph Platform.
  13. Supervisor/sub-agent pattern; per-node model selection enables cross-provider spawning. Subagents docs.
